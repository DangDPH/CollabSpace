## 5.2. Integration and Final Result of the Real-Time System

The real-time system is fully integrated into the web application, resulting in a highly responsive and unified collaborative workspace. By decoupling high-frequency event signaling into a dedicated Node.js and Socket.IO microservice, the application seamlessly supports concurrent live whiteboard drawing, document editing, and global chat without encountering performance bottlenecks. Participants are organized into isolated rooms upon joining a board, enabling the interface to display live user presence and instantly reflect actions across all connected clients via lightweight delta updates.

Furthermore, the integration features embedded peer-to-peer voice communication powered by WebRTC, allowing users to converse directly within the workspace. The real-time server efficiently handles the rapid exchange of signaling metadata, establishing secure, low-latency audio streams that flow directly between clients. This architectural approach successfully shields the main data-persistence backend from the massive overhead of continuous event streams, culminating in a stable, rich, and scalable collaborative environment.
